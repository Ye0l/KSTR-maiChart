# maiChart

SvelteKit + SVG로 만든 가벼운 Simai 차트 뷰어.

## 실행

Node.js 22.18 이상과 pnpm이 필요합니다.

```sh
pnpm install
pnpm dev --host 0.0.0.0
```

차트 데이터는 `Maichart-Converts/` 서브모듈로 포함합니다. 저장소를 받은 뒤 초기화합니다.

```sh
git submodule update --init --recursive
```

곡 검색 → 차트 선택 → **차트 열기** → 난이도 선택 → **재생**.
상단의 **게임 뷰 / 평면 뷰 / Isometric** 버튼은 각각 독립 토글입니다. 켠 순서대로 표시하며, 껐다 다시 켜면 마지막에 붙습니다.
여러 뷰는 데스크톱 좌우, 모바일 위아래로 배치합니다. 재생 위치·재생 속도는 공유하고, 노트/터치 배속은 뷰마다 따로 설정합니다.
평면 뷰는 왼쪽부터 1~8 레인, 위에서 아래로 진행합니다. SLIDE는 시작·대기·끝만 연결하며 실제 경로는 생략합니다.
TOUCH는 센서 번호에 대응하는 레인에 센서명을 표시하고 중앙 C/C1/C2는 4/5 레인 사이에 표시합니다.
Isometric은 센서 판을 30° 축의 등각 투영으로 눕힙니다. 노트는 판과 평행한 원형 면으로 수직 하강하며, HOLD는 세로 길이로, SLIDE는 공간 경로와 대기·진행 시간에 따른 높이로 표현합니다.
Isometric의 판은 아래쪽에 유지하며 캔버스 높이에 맞춰 낙하 거리를 늘립니다. 노트와 가이드선은 화면 위쪽 밖에서 진입하고, SLIDE 시간축도 같은 높이 배율을 사용합니다.
재생 위치·재생 속도와 노트/터치 배속을 따로 조절할 수 있습니다.
플레이 화면 위에서 휠 아래/위로 앞으로/뒤로 탐색합니다. 모바일은 위로 밀면 앞으로, 아래로 밀면 뒤로 이동하며 브라우저의 네이티브 플릭 관성을 따릅니다(240px = 1초).
직접 탐색하면 자동 재생은 일시정지합니다. 사이드 패널의 스크롤은 재생 위치를 바꾸지 않습니다.
노트/터치 배속은 1.0~10.0(0.25 단위)이며, 표시 시간은 각각 `2000 / 배속` ms입니다.
노트/터치 배속 기본값은 각 뷰에서 각각 6이며, 변경값은 뷰별로 브라우저 `localStorage`에 저장됩니다. 기존 공통 배속 저장값도 각 뷰로 이전합니다.
상단 내비게이터는 고정되며 좌측 차트/정보 패널과 하단 재생바는 작은 버튼으로 접을 수 있습니다.
모바일 좌측 패널은 플레이 화면 위에 하단 시트로 열립니다. 바깥 영역이나 Escape로 닫습니다.

## 범위

- 실제 `maidata.txt`의 메타데이터와 난이도별 노트를 읽습니다.
- TAP, HOLD, TOUCH, TOUCH HOLD, BREAK, EX, SLIDE 및 연결·분기 SLIDE를 표시합니다.
- 단독 TAP/HOLD는 분홍, 같은 시각의 동시입력은 노랑입니다. BREAK의 주황색이 최우선이며 HOLD 끝이나 SLIDE 트랙은 동시입력 수에 포함하지 않습니다.
- BPM·박자 분할 변경, 길이, SLIDE 대기시간을 해석합니다.
- 버튼 위치는 `simai_spatial_reference/spatial_reference.json`, B/E 센서 윤곽과 터치 위치는 제공된 공식 스킨을 측정한 `src/lib/sensor-layout.ts`를 사용합니다.
- SLIDE 경로와 구간별 이동은 시각화용 근사치입니다. 원본 게임과의 정밀 일치를 보장하지 않습니다.
- 음원·판정·점수·입력 플레이는 없습니다. 미지원 표기는 화면에 경고하고 건너뜁니다.
- 차트는 서버의 로컬 디스크에서 읽으므로 정적 호스팅 전용 구성은 아닙니다.

## 검증

```sh
pnpm test    # 파서·경로 단위 테스트와 저장소 전체 차트의 유한 시간/좌표 검사
pnpm check
pnpm build
```

Chromium 설치 및 개발 서버 실행 후 `node --test tests/layout.test.mjs`로 패널 토글·뷰 전환·평면 노트 이동·공통 색상·배속 저장·모바일 오버레이를 검사합니다.
포트가 다르면 `VIEWER_URL=http://localhost:5174/ node --test tests/layout.test.mjs`처럼 지정합니다.
전체 차트 검사는 원본 재생과의 일치 검사가 아닙니다.
차트 데이터의 이용 조건과 저작권 안내는 `Maichart-Converts/Readme.md`를 확인하세요.
